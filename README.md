# Talking Travel — вёрстка макета

Учебный проект по семантической и адаптивной вёрстке. В проекте будут две страницы макета Talking Travel: главная и статья блога. Используются только HTML и CSS.

- [Макет в Figma](https://www.figma.com/design/xC3VHAMZNq9Nm9x2TgnHei/Locofy-Sample-Project---Talking-Travel--Community-)
- Опубликованная версия: будет добавлена после публикации через GitHub Pages.

## Структура проекта

- `index.html` — главная страница;
- `blog.html` — страница статьи;
- `css/style.css` — токены, базовые стили и компоненты;
- `img/` — изображения и иконки;
- `docs/decomposition.md` — декомпозиция и оценка;
- `docs/tokens.md` — словарь дизайн-токенов;
- `docs/screenshots/` — проверка на контрольных ширинах.

## Планирование

До написания разметки составлены [декомпозиция и оценка](./docs/decomposition.md), а также [словарь токенов](./docs/tokens.md). Для задач использована трёхточечная оценка PERT.

## Принятые решения

- На промежуточных ширинах колонки перестраиваются по содержимому, а не по названию устройства.
- На узком экране основная навигация раскрывается стандартным элементом `details`, поэтому программная логика не нужна.
- Длинные заголовки переносятся, фиксированная высота текстовых блоков не используется.
- Повторяющиеся цвета, интервалы и радиусы вынесены в пользовательские свойства CSS.
- Видимый фокус сохраняется для всех ссылок и кнопок.

## Проверка

Перед сдачей будут проверены:

- HTML и CSS валидаторами;
- заголовки, ориентиры и альтернативные тексты;
- клавиатурная навигация и видимый фокус;
- отсутствие горизонтальной прокрутки на `360px`;
- раскладка на `360px`, `768px` и `1280px`;
- открытие ссылок и изображений в опубликованной версии.
