| Проверка | Результат |
|---|---|

## Семантика и доступность

- на каждой странице найден ровно один `main` и один `h1`;
- пропусков уровней в последовательности `h1` → `h2` → `h3` нет;
- все изображения имеют атрибут `alt`;
- шапка, основная область, навигация и подвал размечены смысловыми элементами;
- текущий пункт навигации отмечен `aria-current="page"`;
- при проверке клавишей Tab фокус проходит по ссылке пропуска, логотипу, навигации и элементам содержимого в визуальном порядке;
- каждый сфокусированный элемент получает видимую сплошную обводку;
- мобильное меню доступно с клавиатуры через стандартный элемент `details`/`summary`.

## Принятые решения после проверки

- подпись главного изображения статьи ограничена по ширине, чтобы не пересекаться с кнопкой воспроизведения на экране 360 px;
- изображения ниже первого экрана загружаются отложенно;
- фиксированная высота применяется только к изображениям с `object-fit`, текстовые блоки растут по содержимому;
- основной фиолетовый цвет имеет контраст 4,64:1 с белым и подходит для обычного текста.
